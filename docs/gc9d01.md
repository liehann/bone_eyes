# GC9D01 / Waveshare 0.71" notes

- **Library choice:** stock TFT_eSPI (2.5.43, master as of 2026-04) has no
  GC9D01 driver. PR #3783 adding one is still open.
  - Waveshare's demo bundles a patched TFT_eSPI 2.5.0 that replaces the
    GC9A01 branches.
  - Arduino_GFX ≥ 1.6.1 has `Arduino_GC9D01`.
  - We use neither. `src/gc9d01.{h,cpp}` drives ESP-IDF `spi_master`
    directly: manual CS per panel, manual DC, DMA from two 8-row internal-RAM
    buffers. That's about 200 lines, and it gives full control over
    two-panel CS handling with no library patching.
  - Each panel has its own lead. The right eye's CLK/DIN are copies of the
    VSPI signals routed through the GPIO matrix (`Gc9d01Bus::mirror`), and
    its DC/RST/BL follow the left eye's.
- **Init sequence:** verbatim from Waveshare `GC9D01_Init.h`, byte-identical
  to Arduino_GFX.
- **Geometry:** GRAM is 160×160 with no column/row offsets.
- **MADCTL:** MY 0x80, MX 0x40, MV 0x20, ML 0x10. RGB is 0x08 and BGR is 0x00,
  the reverse of the usual convention.
  - The panel runs dual-gate (`0xBF=0x01`). With MV set (90°/270°), even and
    odd lines swap unless ML is set (Arduino_GFX commit 42e6ce8a).
  - We only use 0° and 180° (MX|MY), so this doesn't apply.
- **SPI clock:** the datasheet write cycle is 10 ns min. Waveshare's demo uses
  27 MHz and DualEye_display uses 40 MHz. We default to 40 MHz.
- **Module:** RT9193 3.3 V LDO; V2 boards add a TXB0108 level shifter.
  - RST has an on-board RC power-on reset.
  - BL is active high through an NPN, defaults on when floating, and PWMs fine.
